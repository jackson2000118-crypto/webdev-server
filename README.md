# webdev-server — Lab 5

Sibling Express project for the existing Next.js client.

```sh
npm install
npm run dev
```

`npm start` runs without nodemon. `npm run typecheck` checks TypeScript.
The server listens on `PORT` or 4000. CORS and JSON body parsing run before routes.
Data is stored in process memory and resets on every server restart.
All chapter 5.1–5.3 Express exercises, including On your own routes, are included.
See `../START-HERE.md` and `../CHECKLIST.md` in the original download package.
